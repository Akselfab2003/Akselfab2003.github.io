# Portfolio

Static site — plain HTML, CSS and JS. No build step.

## Edit
- **Your details:** `assets/site.js` → `CONFIG` (name, email, GitHub, LinkedIn, fraud repo, CV).
- **Skills:** `assets/site.js` → `SKILLS` (`strong` / `working` / `familiar`).
- **Fraud pipeline progress:** `projects/fraud-pipeline.html` → `ROADMAP` list.

## Publish on GitHub Pages
1. Create a repo named `<your-username>.github.io` (or any name).
2. Push everything in this folder to the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
4. Live at `https://<your-username>.github.io/` within a minute or two.
