WhyMotivation

I passed AZ-900 in October 2026 and wanted hands-on Azure work to match it — something with real moving parts rather than a tutorial app. Fraud detection is a good fit: it needs data, messaging and processing working together, and it's a problem where thinking like an attacker is part of the job.

ApproachPrinciples
  • Everything as code. Infrastructure is defined in Bicep, so the whole environment can be reviewed, versioned and recreated.
  • Built in the open. The code lives on GitHub, so progress is visible step by step.
Risk & reliabilityPerspective
Attacker thinking, inverted

Most of my security work is about how a system can be broken. This project turns that around: model what fraudulent behaviour looks like, then build the system that catches it.
